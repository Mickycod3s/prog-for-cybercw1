About This Coursework
This repository contains the five Python exercises for programming coursework 1.

Tasks

1. Security Tool

A Python security tool that includes initial login authentication, a security event counter, brute-force simulation and login authentication.

   Branch: security-tool


2. Security Event Logger
A Python program that records successful and failed login attempts, including event IDs, usernames, IP addresses and timestamps.

   Branch: security-event-logger


3. IP Address Validator
A Python function that checks the basic format of an IPv4 address using string operations and numerical validation.

   Branch: ip-address-validator


4. Security Incident Manager
A Python program using dictionaries to store, update, remove and display security incident information.

   Branch: security-incident-manager


5. Cyber Security Utilities
A collection of reusable Python functions organised into a separate module. Includes password validation, IP address validation and random password generation.

   Branch: cyber-security-utilities
