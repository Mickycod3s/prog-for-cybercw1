Task - Security Tool
------

this is a python security tool that asks for login authentication where you can then choose from a security event counter, brute-force simulation and login authentication.


1. security event counter:
 
  - this will ask for a password 10 times
  - after 10 attempts it will count the number of correct and incorrect attmepts
  - if there is more than 50% incorrect attempts it will raise an alert

2. brute-force simulation:
  - uses a predefined password with maximum number of attempts
  - counts the number of attempts
  - will stop if correct password is entered
  - stops when maximum number is reached
  
3. login authentication:
  - asks for a username and password allowing a maximum number of attempts
  - will display if authentication was successful or not
  - after 3 failed attempts it will display a message stating account is frozen for 24 hours

4. exit
 - exits the program
